Why Windows doesn't do this already

Wireless headsets from SteelSeries, Logitech, Corsair, HyperX and others talk to a USB dongle. When you turn the headset off the dongle stays plugged in, so Windows still sees a working "headphones" device and keeps playing into it.

HeadsetAutoSwitch asks the dongle every two seconds whether the headset is actually connected, using the same status message the brand's own software uses for the battery readout. When the answer changes, it sets the matching device as your default output. Here's what that looks like for an Arctis Nova 5:

dongle  ◄── 00 B0             status request
        ──► 00 B0 02 ...      02 = headset off  → speakers
        ──► 00 B0 03 ...      03 = headset on   → headset

Install

  1. Download

    HeadsetAutoSwitch.exe from the latest release.

  2. Double-click it

    It copies itself to %LOCALAPPDATA%, adds itself to Startup and starts running.

  3. Turn your headset off

    Sound moves to your speakers. Turn it on again and it comes back.

Windows SmartScreen may warn about an unrecognized app because the exe isn't code-signed. Choose More info → Run anyway, or build it yourself with build.bat. Windows already includes the compiler it needs.

To uninstall, press Win + R and run %LOCALAPPDATA%\HeadsetAutoSwitch\HeadsetAutoSwitch.exe --uninstall

Any other headset? Teach it in a minute

If your headset isn't recognized, the installer offers to learn it. You can also run it any time with HeadsetAutoSwitch.exe --learn. You turn the headset off and back on once while it watches three things:

🔌

Windows devices

Does the headset's audio output appear and disappear?

❓

Status requests

It sends the read-only status queries known for your dongle's brand and compares the answers.

📣

Dongle messages

Many dongles announce "connected" and "disconnected" on their own. It catches those.

It keeps whichever signal cleanly separates on from off, saves it, and starts using it. If none does, it writes a log you can attach to an issue so support can be added for everyone.
